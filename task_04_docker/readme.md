# ⚡ Energy Market Dashboard (Docker Edition)



Сервис для мониторинга энергетического рынка с использованием FastAPI (Backend) и Streamlit (Frontend), полностью контейнеризированный с помощью Docker Compose.



## 📁 Структура проекта

\- `backend/` — API на FastAPI (порт 8888 внутри контейнера 8000)

\- `frontend/` — Дашборд на Streamlit (порт 8889 внутри контейнера 8501)

\- `requirements.txt` — Общие зависимости проекта

\- `docker-compose.yml` — Конфигурация запуска сервисов



## 🚀 Сборка и запуск



### 1. Автоматический запуск (рекомендуется)

Находясь в папке `task\_04\_docker`, выполните команду:

```bash

docker compose up --build

```



### 2. Сборка образов вручную

Если нужно только собрать образы без запуска:

```bash

docker compose build

```



### 3. Остановка сервиса

```bash

docker compose down

```



## 🌐 Доступ к сервисам

После запуска проект будет доступен по адресам:

\- **Дашборд (Интерфейс):** [http://localhost:8889](http://localhost:8889)

\- **Документация API (Swagger):** [http://localhost:8888/docs](http://localhost:8888/docs)



## 🛠 Инструкция по использованию



### 1. Загрузка данных

В левой панели (сайдбаре) выберите CSV файл через кнопку **Browse files**. 

\- Система автоматически отправит файл в API.

\- Данные сохраняются в `backend/data.csv` и не пропадают после перезагрузки контейнера.



### 2. Управление просмотром

Используйте слайдеры в сайдбаре:

\- **Размер окна:** количество строк, отображаемых на графиках и в таблице.

\- **Смещение:** прокрутка данных вперед/назад по времени.



### 3. Работа с записями (CRUD)

\- **Добавление:** Заполните форму внизу сайдбара. ID записи генерируется автоматически (Max ID + 1).

\- **Удаление:** Введите ID существующей записи и нажмите кнопку удаления. Система выдаст ошибку, если ID не найден.
